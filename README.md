# Manga Tracker

A manga tracking application currently under development.

## getting started

The main application code is located in the `app-init` directory.

### Setup

1. Navigate to the `app-init` directory:
   ```bash
   cd app-init
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```
